# Root CAD 강의 기능 점검

점검일: 2026-10-18. 대상은 [건축클래스 13강](https://www.youtube.com/playlist?list=PLlToPTPzQcmt6QLPeeSIek7yvZOTVyqub)과 [오토데스크코리아 10강](https://www.youtube.com/playlist?list=PLcL2ZDJp8GzzKGzo6B4bSLkBsq8eK8S2O)입니다.

**강의 전체를 동일한 화면·동작으로 재현한 인증은 아닙니다.** 공개 재생목록의 제목과 확인 가능한 챕터를 기준으로 소스를 대조하고, 직접 만든 도형으로 명령과 저장 흐름을 검증했습니다. 모든 영상의 전체 자막·실습 파일·세부 옵션을 확보하지 못했으므로, 아래의 ‘지원’도 해당 강의의 모든 조작을 보증하지 않습니다. 강의 도면이나 Autodesk 자산을 복제하지 않았습니다.

## 이번 반영

- 창 제목, 시작 화면, 메뉴, 정보 창, 웹 화면과 번역의 제품명을 **Root CAD**로 변경했습니다. 원본 CADCraft 저작권·기여자 표시는 유지합니다.
- Windows 실행 파일은 `target/debug/root-cad.exe`, CLI는 `root-cad-cli.exe`입니다. 기존 파일명도 호환 빌드 대상으로 남깁니다. 내부 crate·설정 식별자 `cadcraft`를 유지해 기존 설정을 이어 씁니다.
- `D`, `DDIM`, `DIMSTYLE`로 치수 스타일 창을 엽니다. 스타일 생성·현재 스타일 지정, 문자 높이, 화살표 크기, 정밀도, 축척, 치수보조선과 기준선 간격 등을 편집합니다. 전체 AutoCAD DIMSTYLE 탭을 재현한 것은 아닙니다.
- `FIND`로 찾기/바꾸기 창을 엽니다. 한글, 대소문자 구분, 전체 단어, 모두 찾기/바꾸기를 지원합니다. 현재 모형 또는 배치 공간이 대상이며, 중첩 블록 정의 전체 검색은 아닙니다.
- `QLEADER` 또는 `LE`: 시작점 → 다음 점 → 세 번째 점(또는 두 점 후 Enter) → 주석을 입력합니다. 직선 지시선과 문자 생성은 UNDO 한 번으로 취소됩니다. 기존 MLEADER도 사용할 수 있습니다. 고급 QLEADER Settings는 아직 없습니다.
- JSON/MCP 호출은 기존처럼 매개변수를 받아 실행하며 대화상자를 열지 않습니다.

## 강의별 대응

‘기본 지원’은 대응 엔진 명령이 존재한다는 뜻입니다. ‘부분 지원’은 아래에 적은 차이가 있습니다. ‘종합 실습 미재현’은 구성 명령은 있어도 영상 도면 전체를 따라 그린 검증을 하지 않았다는 뜻입니다.

| 강의 | 주제 | 대응 및 판정 |
|---|---|---|
| 건축 1 | 인터페이스·환경설정 | 부분 지원: Options, 패널·도구 모음, 명령행. AutoCAD 리본/작업공간과 UI가 다름 |
| 건축 2 | 기본 조작·동적 입력·좌표 | 기본 지원: 절대·상대·극좌표, 확대/이동, 스냅·직교·동적 입력. 임의 UCS는 별도 미지원 |
| 건축 3 | 기본 그리기 | 기본 지원: LINE, PLINE, RECTANG, CIRCLE, ARC |
| 건축 4 | 기본 수정 | 기본 지원: MOVE, COPY, ROTATE, MIRROR, OFFSET, TRIM, EXTEND |
| 건축 5 | 추가 그리기 | 기본 지원: POLYGON, ELLIPSE, SPLINE, HATCH, TEXT/MTEXT 등. 영상의 모든 옵션은 미검증 |
| 건축 6 | 추가 수정 | 기본 지원: FILLET, CHAMFER, BREAK, STRETCH, LENGTHEN, ARRAY 등. 모든 특수 형상 조합은 미검증 |
| 건축 7 | 건축 도면 계획·완성 | 종합 실습 미재현: 레이어, 선종류, 문자, 치수, PDF 출력 사용 가능 |
| 건축 8 | 종합 연습 | 종합 실습 미재현: 구성 명령 제공. 영상과 같은 전체 도면 비교는 남음 |
| 건축 9 | 입면도 | 2D 선·블록·치수로 수동 제도 가능. 자동 평면→입면 생성은 없음 |
| 건축 10 | 58평 주택 평면 분석 | 도면 분석 강의. 객실·욕실 구성의 자동 설계/법규 검증은 없음 |
| 건축 11 | 단면도 구조 | 2D 수동 제도 가능. 구조 계산이나 BIM 자동 단면은 없음 |
| 건축 12 | 단면도 마감 | 해치·레이어·상세 문자로 수동 제도 가능. 강의의 외부 패턴/폰트는 미포함 |
| 건축 13 | 단면도 완성 | 종합 실습 미재현: 치수·지시선·표·출력 사용 가능 |
| 공식 1 | 인터페이스·작업공간·선택 | 부분 지원: 선택 방식과 패널 지원, AutoCAD 작업공간/CUI 파일 호환 없음 |
| 공식 2 | 좌표·상태막대·선·지우기 | 기본 지원: 좌표 입력, LINE, ERASE, 스냅/직교 등 |
| 공식 3 | 원·호 | 기본 지원: 중심/반지름, 지름/두 점/세 점, 세 점 호 등 |
| 공식 4 | 다각형·폴리선·레이어·선종류·길이 | 기본 지원: POLYGON, PLINE, LAYER, LINETYPE, LENGTHEN |
| 공식 5 | 이동·복사·대칭·끊기·모따기·모깎기 | 기본 지원: MOVE, COPY, MIRROR, BREAK, CHAMFER, FILLET |
| 공식 6 | 문자 스타일·문자·다중문자·찾기 | 기본 지원 + FIND 창 추가. SHX 글꼴 로더는 없음, 설치된 TTF 글꼴 사용 |
| 공식 7 | 치수 스타일·치수 편집·치수 명령 | 기본 지원 + DIMSTYLE 창 추가. 일부 고급 치수 변수/관리 UI는 미지원 |
| 공식 8 | 다중지시선·빠른지시선·축척·신축 | 기본 지원 + QLEADER 추가. 고급 QLEADER Settings는 미지원 |
| 공식 9 | 표·블록·클립보드·도구 팔레트 | 부분 지원: TABLE/수식, BLOCK/INSERT/BEDIT, COPYCLIP/PASTECLIP. Tool Sets/블록 목록은 있지만 사용자 도구 팔레트 완전 호환은 없음 |
| 공식 10 | 해치·스플라인·배열·빠른선택·출력·단축키 | 부분 지원: HATCH, SPLINE, ARRAY, QSELECT, 페이지 설정/PDF. CTB/STB/PC3 파일·시스템 프린터와 CUI 키보드 사용자화는 미지원 |

공식 9강의 51:49 항목은 **클립보드/도구 팔레트**입니다. 이를 XCLIP 강의로 잘못 분류하지 않았습니다. 공식 10강 챕터는 해치/스플라인(00:18), 배열(15:48), 빠른선택(26:25), 플롯 스타일(37:33), 출력(45:36), 단축키 사용자화(59:52)입니다.

## 검증과 후속 개선

새 회귀 테스트: `crates/engine/tests/course_workflows.rs`, `crates/ui-egui/tests/root_course_dialogs.rs`. 좌표 폐합, 레이어·길이 수정·복사·대칭, 원/호/다각형/스플라인/해치/빠른선택, 한글 찾기/바꾸기와 UNDO, 치수·지시선 DXF 왕복, 표 수식·클립보드, PDF 출력을 대상으로 합니다. 창 호출과 JSON 실행 경로도 분리해 확인합니다.

아래는 별도 구현·검증이 남은 항목입니다. 현재 기능으로 숨기거나 ‘완료’로 표시하지 않습니다.

1. 사용자 도구 팔레트의 저장·분류·드래그 삽입, 명명된 작업공간 전환.
2. 임의 키 조합·매크로의 영구 사용자화. 현재 ALIASEDIT/PGP 명령 별칭은 키보드 단축키 전체 사용자화와 다릅니다.
3. 외부 CTB/STB/PC3 설정과 시스템 프린터 연결. 현재 페이지 설정·자체 플롯 스타일·PDF 출력을 사용합니다.
4. SHX 글꼴과 Excel 연결 표. 현재 TTF와 CSV 연결을 사용합니다.
5. DIMSTYLE의 나머지 고급 설정·미리보기, QLEADER 고급 설정, 임의 UCS.
6. 각 영상의 실습을 원본 자산 없이 새 도면으로 끝까지 재현하는 수동 검증.

즉, 일반 2D 제도와 강의의 주요 명령을 연습할 기반은 있지만 **23개 강의의 모든 기능·UI가 완전히 동일하다고 결론 내릴 수는 없습니다.**

### 현재 확인 결과

- 엔진 회귀 테스트 8개와 UI 회귀 테스트 4개, 총 12개 통과.
- 핵심 엔진·입출력 WASM 빌드와 Clippy 경고 검사 통과.
- 전체 번역 TSV의 행 형식과 대소문자를 구분한 키 중복 검사 통과.
- Windows 새 GUI 자동 실행, MCP 연결, 도면 생성·DXF/PDF 저장·렌더링·PDF 벡터 가져오기 확인.
- 한국어 DIMSTYLE/FIND 실제 창 확인. FIND 입력·모두 찾기·모두 바꾸기·UNDO를 실제 UI 클릭으로 확인.
- 새 GUI와 CLI의 버전 출력 및 창 제목이 Root CAD임을 확인. 예제 DXF/PDF/PNG 생성 완료.
- Codex MCP의 기존 cadcraft 항목을 root-cad-cli.exe / 127.0.0.1:7980으로 갱신. Claude용 설정은 dist/mcp-claude.json에 생성.
- Windows 아이콘/버전 리소스 컴파일러는 현재 로컬 GNU 도구 구성에서 작동하지 않아 실행 파일의 Explorer 아이콘/세부 메타데이터는 이번 빌드에 포함되지 않았습니다. 창 제목과 실행 파일명은 변경되었습니다.

### 실행과 예제

프로젝트 폴더의 `Start-RootCAD.cmd`를 실행합니다. 예제는 PowerShell에서 `.\scripts\Create-CourseDemo.ps1`로 생성할 수 있습니다. 결과는 `dist/root-course-demo.dxf`, `.pdf`, `.png`입니다. 이 예제는 원본 강의 도면과 무관한 연습용 도면입니다.
